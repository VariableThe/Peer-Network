System architecture

Each peer keeps its own SQLite file — peer1, peer2, peer3.db — while DataTransfer.sol on Ganache (127.0.0.1:8545) records every request and response. Tables never leave the peer; only results travel.

  • createRequest with target + SQL; RequestCreated event fires
  • Target peer queries locally via peerz.py
  • submitResponse; requester reads getRequest
“The chain coordinates, peers own their data.”
